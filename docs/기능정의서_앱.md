# GateON 기능정의서 — 앱 (모바일)

> 대상: 모바일 앱 (`lib/features/`) — iOS / Android

| 대분류 | 중분류 | 소분류 |
|---|---|---|
| 앱 실행 | 초기 구동 | 디바이스 ID 발급, 상태 복원, 업체코드 확인 |
| 앱 실행 | 진입 | 스플래시, QR 딥링크 진입 |
| 권한/약관 | 약관 동의 | 개별 동의, 전체 동의 |
| 권한/약관 | 권한 요청 | 카메라, 위치, 블루투스, NFC |
| 권한/약관 | 안내 | 사용 가이드 |
| 차단 | 차단 방식 | QR 차단, NFC 차단, 비콘 차단, 수동 차단 |
| 차단 | 차단 실행 | 카메라 비활성화(AND), 차단 프로파일 설치(iOS) |
| 차단 | 차단완료 | 차단완료 전송(C_DISABLE) |
| 해제 | 해제 방식 | QR 해제, NFC 해제, 비콘 해제, 수동 해제, 위치기반 해제 |
| 해제 | 해제 실행 | 카메라 활성화(AND), 해제 프로파일 설치(iOS) |
| 해제 | 해제완료 | 해제완료 전송(C_ENABLE), 해제 알림음 |
| 상태 감시 | 주기 감시 | 1초 주기 상태 체크, 앱 복귀 시 즉시 재평가 |
| 상태 감시 | 보안 | 캡처 방지, 차단/해제 알림음 |
| 다른 MDM 감지 | 감지 | 다른 MDM 차단 판별 |
| 다른 MDM 감지 | 안내 | 다른 MDM 다이얼로그, 정상화면 유지 |
| 비정상 감지 | 프로파일 삭제 | 차단 프로파일 삭제, 해제 프로파일 삭제 |
| 비정상 감지 | 비정상 처리 | 비정상 기록, 차단화면 이동, 무단 카메라 복원 감지(AND) |
| 차단(Ban) | 비정상 안내 | 비정상 접근 안내, 디바이스 ID 표시 |
| 차단(Ban) | 관리자 해제 | 관리자 코드 해제, 해제 후 초기화 |
| 기기 보안(Knox) | 라이센스 | Knox 라이센스 활성화, 라이센스 상태 수신, 활성화 오류 처리 |
| 기기 보안(Knox) | 디바이스 관리자 | 관리자 권한 활성화, 강제 활성화, 관리자 해제 방지 |
| 기기 보안(Knox) | 앱 보호 | 앱 삭제 방지, 앱 삭제 제어(요청/강제) |
| 기기 보안(Knox) | 카메라 제어 | 카메라 하드웨어 차단/해제(Knox HW Control) |
| 기타 | 네트워크 | 인터넷 연결 감지 |
| 기타 | 분석 | Firebase 분석/크래시 |

---

### 차단/해제 방식 매트릭스

| 방식 | 차단 | 해제 |
|---|---|---|
| QR | ✓ | ✓ |
| NFC | ✓ | ✓ |
| 비콘(Beacon) | ✓ | ✓ |
| 수동(코드) | ✓ | ✓ |
| 위치기반 | — | ✓ |

> 각 방식의 사용 여부는 웹 관리자 **설정**의 기능 스위치로 ON/OFF 제어

> 표기: (AND) = Android 전용, (iOS) = iOS 전용, 표기 없음 = 공통
> 기기 보안(Knox)은 **삼성(Samsung) 단말 전용** 기능 — Knox SDK 기반. 비삼성 Android는 일반 Device Admin으로 동작
