# GateON 기능정의서 — 웹 (관리자 페이지)

> 대상: 데스크톱 관리자 웹 (`lib/admin/`)

| 대분류 | 중분류 | 소분류 |
|---|---|---|
| 계정/인증 | 로그인 | 로그인, 로그아웃, 로그인 상태 유지 |
| 계정/인증 | 권한 관리 | 최고관리자, 업체관리자, 서브관리자, 권한별 화면 분기 |
| 대시보드 | 방문 현황 | 누적 방문객 수, 금일 방문객 수 |
| 대시보드 | 차단 현황 | 금일 차단 방문객 수, 아이폰 비정상 방문객 수 |
| 대시보드 | 차트 조회 | 일별 통계, 월별 통계, 기간 변경 |
| 업체 관리 | 업체 목록 | 목록 조회, 검색, 정렬/필터 |
| 업체 관리 | 업체 상세 | 상세 조회, 이력 조회 |
| 업체 관리 | 업체 등록/수정 | 등록, 수정, 로고/파일 업로드 |
| 디바이스 관리 | 디바이스 목록 | 목록 조회, 검색, 정렬/필터 |
| 디바이스 관리 | 디바이스 등록 | 등록, 유형 지정(QR/NFC/비콘/위치) |
| 디바이스 관리 | 디바이스 편집 | 수정, 삭제 |
| 이용자 관리 | 이용자 목록 | 목록 조회, 현재 차단 이용자 수, 검색, 정렬/필터 |
| 이용자 관리 | 이용자 상세 | 상세 조회 |
| 이용자 관리 | 이력 관리 | 방문/차단 이력 조회 |
| 이용자 관리 | 데이터 | 엑셀 다운로드 |
| 서브관리자 관리 | 서브관리자 목록 | 목록 조회, 검색, 정렬/필터 |
| 서브관리자 관리 | 서브관리자 상세 | 상세 조회 |
| 서브관리자 관리 | 서브관리자 계정 | 생성, 수정 |
| 설정 | 차단/해제 방식 | QR, NFC, 비콘, 수동, 위치기반 ON/OFF |
| 설정 | 위치 설정 | 주소 검색, 해제 반경 설정 |
| 설정 | 업체 정보 | 로고/파일 변경 |
| 설정 | 보안 | 비밀번호 변경 |

---

### 권한별 접근 메뉴

| 권한 | 접근 가능 메뉴 |
|---|---|
| 최고관리자 (ROLE_ADMIN) | 업체 관리, 디바이스 관리 |
| 업체관리자 (ROLE_ENTERPRISE) | 대시보드, 이용자 관리, 디바이스 관리, 서브관리자 관리, 설정 |
| 서브관리자 (ROLE_ENTERPRISE_SUB) | 대시보드, 이용자 관리, 설정 |
